Ducati 仿賽車款年代圖鑑 V2 — 可編輯網站

開啟方式
1. 解壓縮後，直接雙擊 index.html。
2. index.html 已把 CSS 與 JavaScript 全部內嵌，不需要架設伺服器，也不會因相對路徑失去版面。

本版調整
- 主圖鑑：49 款，保留獨立車系、重大機械版本、認證車與實質性能版本，並分成 V2 仿賽線、V4 仿賽線與公路運動支線。
- SuperSport 937／950 為公路運動支線，不排入 899 → 959 → Panigale V2 的接班關係。
- 紀念與特殊塗裝：3 款，集中收錄 30° Anniversario 916、V4 Tricolore、V2 MM93／FB63。
- 特仕版不列入主世代數。
- 搜尋與篩選可同時作用於分區與特仕區塊。

檔案
- index.html：完整可編輯網站，CSS／JavaScript 均已內嵌。
- data/models.json：全部 52 款結構化資料，section 欄位標示 main 或 special。

換圖片
目前圖片使用網路縮圖網址。正式公開網站時，建議改用自有或已授權照片，再把 img 的 src 改成本地圖片路徑。
